## Installation

1. Save the APK to Files on your iPhone.
2. With your green-display Rokid AI Glasses connected, open **Hi Rokid → Home → Toolbox → Glasses app management**.
3. If **Upload APK** is available, select the APK and follow the installation prompts.
4. Open **IyoTube** on the glasses. Connect through **Wi-Fi settings**, then select **Browse YouTube** or **Search or open link**.

If Android reports a signature mismatch, uninstall the previously installed build before installing this APK. Uninstalling clears saved app data.
